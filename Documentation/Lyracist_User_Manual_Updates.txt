Lyracist Pro & KSRotation - Performer Portal Update (August 2026)

Section: Connect & Request Instructions Screen / Wi-Fi Password Manager

[Update Details]
A dedicated Connect & Request Instructions feature has been added to display scan-to-connect Wi-Fi and song request QR codes directly on projection monitors.

1. Scan-to-Connect Wi-Fi & Song Request Dual QR Code Banner:
   - Automatically detects active Wi-Fi network SSID and song request portal URL.
   - Generates a dynamic vector graphic (`ConnectInstructions.png`) featuring a WPA/WPA2/NoPass Wi-Fi scan-to-connect QR code (forest green `#064E3B`) and a song request portal QR code (pure black `#000000`).
   - Clearly displays Wi-Fi network SSID, password status ("No Password Required" or explicit password), and portal URL.

2. Dynamic Target Screen Resolution Detection:
   - Automatically detects the physical pixel dimensions (`width` x `height`) of the target display monitor (`1080p`, `1440p`, `4K 3840x2160`, etc.).
   - Dynamically scales vector paths, fonts, card bounds, and QR code module density (`pixelsPerModule`) to guarantee razor-sharp 1:1 pixel rendering on any screen size.

3. Persistent Wi-Fi Password Store (`wifi_passwords.json`):
   - Automatically remembers Wi-Fi passwords entered for specific SSIDs (venue Wi-Fi, travel router, mobile hotspot).
   - Upon detecting a connected Wi-Fi network SSID, the application automatically recalls and populates the saved password into the Wi-Fi password input box.
   - Entering or updating a password automatically updates `wifi_passwords.json` for that SSID.

4. Dedicated Green GroupBox Layout & Screen Selector:
   - Located in the Display settings tab inside a dedicated Green GroupBox styled under Column 1 (directly under Display & Projection).
   - Features a dedicated **Target Screen / Monitor** selection dropdown with options: "None", "All Screens / Monitors", or individual connected display monitors.

Section: Singer Request Board / Patron Request Portal

[Update Details]
A new online search capability has been added directly to the patron request portal.

1. Online Song & Artist Lookup:
   - When users access the Patron Request Portal via QR Code, they will see a new field labeled "Search Songs & Artists (Online)".
   - Type query keywords (such as the song name or artist) to query the iTunes search index in real-time.
   - Tap any suggestion from the search results list to automatically populate the "Song Title" and "Artist Name" fields in the form.

2. Connection Dependency:
   - This feature runs on the patron's mobile browser, using the patron's own internet connection (via mobile data or internet-enabled Wi-Fi).
   - The host system (main KJ laptop/tablet) does NOT require internet or external drives connected for this search to function.

3. Graceful Offline Fallback:
   - If the patron's phone has no internet connection (e.g. no cellular signal or local-only hotspot), the search bar will gracefully show a "Search unavailable (offline)" message.
   - The manual entry form remains fully functional under all network conditions.

Section: Display Projection Window / Display Monitor Selection

[Update Details]
Operators can now select a specific monitor for displaying the rotation projection window (Singer Display Window) from a dropdown list of available system screens.

1. Target Monitor Dropdown:
   - Located in the "Settings" tab under a new group titled "Display Monitor".
   - Displays all connected monitors with their indices, bounds, and whether they are primary.
   - When selected, the display window is repositioned on that specific screen.
   - If the selected monitor is unplugged or unavailable, the application falls back automatically to the secondary screen if available, or the primary screen.

2. Dynamic Window Relocation:
   - Selecting a different monitor dynamically moves the active, maximized display window to the target screen immediately without needing to close and re-enable it.

3. Refresh Monitors List:
   - If a new monitor is connected while the application is running, operators can click the "Refresh" button next to the dropdown to scan and reload the system's screen configuration.

Section: Rotation Management / Paused and Inactive Singer Controls

[Update Details]
Updates have been made to both the main console and the DJ web portal to manage paused and deleted (inactive) singers more effectively.

1. Paused Singers:
   - Operators can pause a singer using the Pause button in the console or the remote DJ portal.
   - Paused singers retain their index/position in the rotation list, but their row is grayed out.
   - Paused singers cannot be marked as the current singer or next singer until they are explicitly unpaused (resumed). They are automatically skipped in the rotation.

2. Deleted/Inactive Singers:
   - Clicking the Delete (trash can) button no longer deletes a singer from the database. Instead, it marks them as inactive (deleted) and moves them to the end of the rotation list.
   - Inactive singers' rows are grayed out.
   - When a singer is inactive, their delete button icon changes to a "↺" (Restore) button in the console and "Restore" button in the DJ portal.
   - Clicking Restore reactivates the singer and moves them back to the end of the active section in the rotation.

Section: Patron Portal / Background Music & Song Requests

[Update Details]
Patrons can now request background music/song tracks to be played in between karaoke performances directly from the web portal.

1. Karaoke vs. Music Selection:
   - On the Patron Request Portal, users will see a new selector under their name: "Karaoke (Sing)" and "Music (Play)".
   - Selecting "Music" limits the submission to one song, hides the "Add another song" option, and marks the request category as Music.
   
2. DJ Incoming Requests Queue:
   - On the DJ screen and the remote DJ portal web interface, incoming music requests are labeled with a green [MUSIC] badge, distinguishing them from standard purple [KARAOKE] requests.
   - Standard duplicate logic is updated so a singer can have one active karaoke slot and one background music slot simultaneously.

3. Rotation List Layout:
   - Accepting a music request places it in the active rotation queue.
   - For music entries in the queue, the 10 round checkboxes are automatically hidden and replaced by a "♪ Background Music Track" label.
   - On the DJ screen, the name, song, and artist fields of music tracks are highlighted in bold green for easier identification.

4. Projection Display Support:
   - Music requests show up with a "[MUSIC]" prefix in the active list and flip tile board.
   - When a music request is active/next:
     - The projection window's Vegas Marquee style shows "★ BACKGROUND MUSIC ★".
     - The Vinyl Turntable style displays "♪ NOW PLAYING".
     - The Star Wars Crawl renders the entry with a "NOW PLAYING" header, displaying the song title as the primary text, followed by the artist and requester details below.


Section: Database Manager / Catalog Book Exporter

[Update Details]
Operators can now export the entire song database (Karaoke or Music) into Word (.docx) or PDF format directly from the Lyracist Database Manager.

1. Exporter Panel:
   - Located in the right pane of the Lyracist Database Manager under "Catalog Book Generator".
   - Provides two dropdown selectors:
     - Catalog: Choose between the "Karaoke Catalog" (tracks marked as karaoke) and the "Music Catalog" (standard audio tracks).
     - Format: Choose between "Word Document (.docx)" and "PDF Document (.pdf)".
     
2. Generated Fields & Formatting:
   - The generated books are structured as clean, professionally styled tables showing:
     - Artist: Alphabetically ordered performer names.
     - Title: Song titles.
     - Length: Formatted track durations (MM:SS).
     - Genre: The embedded audio genre (automatically populated during metadata scans).
     
3. Pagination & Output:
   - The document is fully paginated, displaying "Page X" or "Page X of Y" in the bottom footer.
   - For Word (.docx) books, a repeating header row is defined so column titles automatically reappear on the top of each page.
   - When generation completes, Lyracist automatically launches the default system viewer to open and print the document, which is saved in the "Reports" directory.

Section: Display Projection Window / DJ Banner and Rotation Screen Collision Priority

[Update Details]
To ensure proper projection setup, priority logic has been added when both the DJ Banner and the Rotation Display target the same screen/monitor.

1. Same-Screen Deconfliction:
   - The DJ Banner will usually be displayed on the screen while everything is getting setup and the list is started.
   - Once the Rotation Display is enabled (or moved) to the same screen, the DJ Banner is automatically disabled and hidden so the rotation list can display.
   
2. Multi-Screen Independent Operation:
   - If the DJ Banner and the Rotation Display target different screens, they will both be displayed and operate simultaneously.



Section: Display Projection Window / Casting Support

[Update Details]
Operators can now select different casting targets for the Singer Rotation Billboard screen in both Lyracist and KSRotation applications, in addition to standard physical monitors.

1. Casting Target Dropdown:
   - Located in the "Settings" tab under "Displays & Projection" (or "Display & Projection" in KSRotation).
   - Dropdown options include Monitor, Miracast, Chromecast, Browser Cast, AirPlay, and Wireless HDMI.
   - When a casting target is selected, the application (Lyracist or KSRotation) initializes the appropriate casting sender/server in the background.

2. Off-Screen Rendering:
   - Selecting a casting target (such as Chromecast or Browser Cast) creates and renders the Rotation Window / Singer Display Window in an off-screen buffer (invisible to the host desktop) to capture frames dynamically.
   - This ensures the KJ laptop screen is not cluttered while casting frames.

3. Browser Cast Server:
   - The self-hosted Browser Cast option spins up a local web server (http://localhost:8080/rotation/) to allow any browser on the local network to view the singer rotation billboard in real-time.

Section: Main Console / Front Page Music Search & Rotation Insertion

[Update Details]
Operators can now search the background music library directly from the main Karaoke dashboard, add tracks to the rotation queue as music, and configure automated playback.

1. Music Library Search Tab:
   - A new "Music Library" tab has been added to the search panel on the front page of Lyracist, positioned next to the "Local Library" tab.
   - Searching via the main search bar queries both the karaoke library and the background music library (tracks where IsKaraoke is false) simultaneously.
   
2. Insertion into Performer Rotation:
   - Displays search results with Song and Artist columns.
   - Click the "Add to Rotation" (+) button or double-click a song in the list to immediately insert the track into the active rotation queue as a music track (highlighted in green and labeled "♪ Background Music Track").
   - Music tracks are added under the generic name "Music Request", bypassing the duplicate check and database persistence, allowing you to insert multiple independent music tracks into different positions in the queue.
   - This provides a convenient mechanism for hosts to interject background music tracks into the main rotation occasionally without requiring a patron request.

3. Auto-Play & Configurable Delay:
   - Added a new control row right below the queue filters on the front page containing an "Auto-Play Rotation Music" checkbox and a "Delay" selector.
   - When checked, background music tracks in the rotation queue will automatically start playing after the previous singer finishes.
   - The delay selector allows customizing how many seconds (0s to 30s) the system waits before starting the music track.

4. Automatic Queue Cleanup:
   - Once a background music track finishes playing and is marked Done, it is automatically removed from the rotation queue rather than remaining for subsequent rounds.

Section: Rotation Advancement & Default Event Banners Update

[Update Details]
Updates have been made to rotation sequence advancement and standard default event banners in KSRotation and Lyracist.

1. Robust 1-Click Rotation Advancement & Rollover:
   - When marking a singer finished (via "Done", "✓", or remote DJ portal), rotation sequence advancement calculates the next active singer sequentially starting after the finished singer's index.

2. "Last Song" Default Event Banner:
   - Added "Last Song" (`LastSong.png`) to the standard pre-saved event banners list alongside Birthday, Wedding, Engagement, and Anniversary.
